Lambda
------
Lambda (anonymous function) 
short function which can be created any time 
can be created inside other function or outside main function

Syntax :: 
[capture] (parameters) {
    // code
};

Example :: 
auto add = [](int a, int b) {
    return a + b;
};
cout << add(10, 20);

Capture List ::
=-=-=-=--=-=
int x = 10;
auto show = [x]() {
    cout << x;
};
show();

[x]       // capture x
[&x]      // capture x by reference
[=]       // capture all required outside variables by value
[&]       // capture all required outside variables by reference
[]        // capture nothing
