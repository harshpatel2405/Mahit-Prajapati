============================================================
           1.  C++ PRACTICAL QUESTION
        HYBRID INHERITANCE - LIBRARY SYSTEM
============================================================

Problem:

Design a C++ program to implement a Library Management System using HYBRID INHERITANCE.

The system should contain the following classes:

                    Library
                   /       \
                  /         \
               Book        Member
                  \         /
                   \       /
                BorrowTransaction


1. Create a class Library with:

   Data Members:
   - libraryName
   - address
   - totalBooks
   - availableBooks

   Member Functions:
   - Constructor to initialize all data
   - showLibraryInfo()

2. Create a class Book that inherits virtually from Library.

   Data Members:
   - title
   - author
   - isbn
   - pages
   - category

   Member Functions:
   - Constructor
   - showBook()


3. Create a class Member that inherits virtually from Library.

   Data Members:
   - memberName
   - memberId
   - membershipType
   - borrowedCount
   - maxBorrowLimit

   Member Functions:
   - Constructor
   - showMember()


4. Create a class BorrowTransaction that inherits from
   BOTH Book and Member.

   Data Members:
   - borrowDate
   - dueDate
   - returnDate
   - finePerDay
   - lateDays

   Member Functions:

   calculateFine()

   The fine should be calculated as:

   fine = lateDays * finePerDay


   showTransaction()

   This function should display:

   -------- LIBRARY DETAILS --------
   Library Name
   Address
   Total Books
   Available Books

   -------- BOOK DETAILS -----------
   Title
   Author
   ISBN
   Pages
   Category

   -------- MEMBER DETAILS ---------
   Member Name
   Member ID
   Membership Type
   Borrowed Count
   Maximum Borrow Limit

   -------- TRANSACTION ------------
   Borrow Date
   Due Date
   Return Date
   Late Days
   Fine Per Day
   Total Fine


5. IMPORTANT REQUIREMENTS:

   a) Use virtual inheritance for Book and Member.

   b) Library should be initialized only once.

   c) Use protected members/functions wherever appropriate.

   d) BorrowTransaction should access information from Library, Book and Member.

   e) Use constructor initialization lists.

   f) Do NOT use global variables.

   g) Create at least one object of BorrowTransaction in main().
