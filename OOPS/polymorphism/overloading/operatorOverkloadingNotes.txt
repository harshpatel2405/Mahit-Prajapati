C++ OPERATOR OVERLOADING
========================

1. WHAT IS OPERATOR OVERLOADING?
-------------------------------
Operator overloading means giving a special meaning to an operator when it is used with objects.

Example: n1 + n2

Here n1 and n2 are objects.

Normally + works with numbers: 10 + 20

With operator overloading, + can work with objects.

2. BASIC SYNTAX
---------------
return_type operator symbol(ClassName object)
{
    // code
}


3. SIMPLE EXAMPLE
-----------------

class Number
{
public:
    int a;

    int operator+(Number n2)
    {
        return this->a + n2.a;
    }
};

int main()
{
    Number n1, n2;

    n1.a = 10;
    n2.a = 20;

    int result = n1 + n2;

    cout << result;
}


4. WHAT HAPPENS INTERNALLY?
---------------------------

When we write:

n1 + n2;

C++ understands it approximately as:

n1.operator+(n2);


5. THIS POINTER
---------------

Example:

int operator+(Number n2)
{
    return this->a + n2.a;
}

Here:
this->a = value of first object
n2.a = value of second object

Example:

n1.a = 10;
n2.a = 20;

n1 + n2

means:

10 + 20

Result = 30


6. OBJECT + OBJECT -> INT
-------------------------

Example:

int operator+(Number n2)
{
    return this->a + n2.a;
}

Usage:

int result = n1 + n2;

Here:

Object + Object -> int


7. OBJECT + OBJECT -> OBJECT
----------------------------

Operator can also return an object.

Example:

Number operator+(Number n2)
{
    Number temp;

    temp.a = this->a + n2.a;

    return temp;
}

Usage:

Number n3 = n1 + n2;

Here:

Object + Object -> Object


8. SUBTRACTION
--------------

We can overload - also.

Example:

Number operator-(Number n2)
{
    Number temp;

    temp.a = this->a - n2.a;

    return temp;
}

Usage:

Number n3 = n1 - n2;

13. COMPARISON OPERATORS
------------------------

We can also overload:

==
!=
>
<
>=
<=

Example:

bool operator==(Number n2)
{
    return this->a == n2.a;
}

Usage:

if(n1 == n2)
{
    cout << "Equal";
}


14. GREATER THAN
----------------

bool operator>(Number n2)
{
    return this->a > n2.a;
}

Usage:

if(n1 > n2)
{
    cout << "n1 is greater";
}


15. UNARY OPERATORS
-------------------

Unary operator works with ONE operand.

Examples:

++
--
-
!


16. PREFIX ++
-------------

void operator++()
{
    a++;
}

Usage:

++n1;


17. POSTFIX ++
--------------

void operator++(int)
{
    a++;
}

Usage:

n1++;


18. PREFIX AND POSTFIX
----------------------

++n1;    -> Prefix

n1++;    -> Postfix


19. DECREMENT --
---------------

void operator--()
{
    a--;
}

Usage:

--n1;


20. UNARY MINUS
---------------

Number operator-()
{
    Number temp;

    temp.a = -this->a;

    return temp;
}

Usage:

Number n2 = -n1;


21. BINARY OPERATOR
-------------------

Binary operator works with TWO operands.

Example:

n1 + n2

Operands:

n1 -> first object
n2 -> second object

Example function:

Number operator+(Number n2)


22. MEMBER FUNCTION
-------------------

Example:

class Number
{
public:

    Number operator+(Number n2)
    {
        Number temp;

        temp.a = this->a + n2.a;

        return temp;
    }
};


23. FRIEND FUNCTION
-------------------

Operator overloading can also be done using a friend function.

Example:

class Number
{
public:
    int a;

    friend Number operator+(Number n1, Number n2);
};

Number operator+(Number n1, Number n2)
{
    Number temp;

    temp.a = n1.a + n2.a;

    return temp;
}


24. IMPORTANT RULE
------------------

You CANNOT overload a function only by changing its return type.

WRONG:

int operator+(Number n);

Number operator+(Number n);

This is NOT allowed.

Reason:

Both have the same:

operator+(Number)

C++ does not use return type to decide function overloading.

27. OPERATOR OVERLOADING VS METHOD OVERLOADING
----------------------------------------------

METHOD OVERLOADING:

Same function name
Different parameters

Example:

void add(int a);

void add(int a, int b);

void add(int a, int b, int c);


OPERATOR OVERLOADING:

Give special meaning to an operator for objects.

Example:

Number operator+(Number n);


28. CONSTRUCTOR OVERLOADING VS OPERATOR OVERLOADING
---------------------------------------------------

CONSTRUCTOR OVERLOADING:

Transaction(int id);

Transaction(int id, string type);

Transaction(int id, string type, bool status);


OPERATOR OVERLOADING:

Number operator+(Number n);

Number operator-(Number n);

Number operator*(Number n);


29. IMPORTANT EXAMPLE
---------------------

class Number
{
public:
    int a;

    int operator+(Number n2)
    {
        return this->a + n2.a;
    }

    Number operator-(Number n2)
    {
        Number temp;

        temp.a = this->a - n2.a;

        return temp;
    }
};

Here:

n1 + n2
-> Object + Object -> int

n1 - n2
-> Object - Object -> Object
